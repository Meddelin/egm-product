# EGM Product (`egm-product`) — Routing & Execution Rules

Because `egm-product` skills set `disable-model-invocation: true`, their descriptions are hidden from passive skill discovery. Whenever the user invokes a `/pm-*` command or asks for Product Management workflows (mapping product/company/role/UI-shell context and metrics, brainstorming feature opportunities & JTBD, writing or reviewing a JTBD + User Story PRD, or building an interactive HTML prototype inside the real product UI canvas), resolve the skill path relative to this plugin directory (`../skills/<skill>/SKILL.md` from `rules/AGENTS.md`) and read the corresponding `SKILL.md` directly:

| Stage / Trigger | Skill File to Read (Relative to `rules/`) | Primary Deliverable & Product Subagents |
| :--- | :--- | :--- |
| **Stage 1: `/pm-discover`** (mapping product strategy, company context, empirical roles, JTBD, UI App Shell & metrics; supports `--scope <subdir>` and `--context <path>`) | [`../skills/pm-discover/SKILL.md`](../skills/pm-discover/SKILL.md) | Scans user-facing product surface & UI shell via `pm-product-scanner` -> writes `PRODUCT_CONTEXT.md`, `METRICS.md`, optional `COMPANY_CONTEXT.md`, and `.pm/ui_tokens.md`. |
| **Stage 2: `/pm-brainstorm`** (shaping a feature idea across JTBD, User Stories, customer demand, roles, alternatives & metrics) | [`../skills/pm-brainstorm/SKILL.md`](../skills/pm-brainstorm/SKILL.md) | Runs the 4+1 Product Goldfish swarm (`pm-value-strategy`, `pm-ux-flows`, `pm-metrics-experiment`, `pm-business-logic` -> `pm-synthesizer`) -> writes `docs/product/<feature-slug>/opportunity_brief.md`. |
| **Stage 3: `/pm-prd`** (drafting a JTBD + User Story PRD + built-in 4+1 Product Goldfish review) | [`../skills/pm-prd/SKILL.md`](../skills/pm-prd/SKILL.md) | Drafts pure-product `docs/product/<feature-slug>/prd.md` with story-driven screen states and polishes it via the built-in 2-round 4+1 Product Goldfish review (`pm_review_report.md`), ready for `/pm-prototype` or engineering handoff. |
| **Stage 4: `/pm-prototype`** (generating an interactive HTML preview 1:1 inside the real product canvas) | [`../skills/pm-prototype/SKILL.md`](../skills/pm-prototype/SKILL.md) | Inspects host frontend App Shell + target screen and `.pm/ui_tokens.md` -> generates zero-build `docs/product/<feature-slug>/prototype.html` with interactive User Story walkthroughs and PRD-driven scenario/state/role switching, audited via `pm-ux-flows` (`Mode: PROTOTYPE_AUDIT`). |
