# EGM Product (`egm-product`) — Routing & Execution Rules

Because `egm-product` skills set `disable-model-invocation: true`, their descriptions are hidden from passive skill discovery. Whenever the user invokes a `/pm-*` command or asks for Product Management workflows (mapping product/company/role context and metrics, brainstorming feature opportunities, writing or reviewing a PRD, or building an interactive HTML prototype from a PRD), resolve the skill path relative to this plugin directory (`../skills/<skill>/SKILL.md` from `rules/AGENTS.md`) and read the corresponding `SKILL.md` directly:

| Stage / Trigger | Skill File to Read (Relative to `rules/`) | Primary Deliverable & Product Subagents |
| :--- | :--- | :--- |
| **Stage 1: `/pm-discover`** (mapping product strategy, company context, empirical roles, UI tokens & metrics; supports `--scope <subdir>` and `--context <path>`) | [`../skills/pm-discover/SKILL.md`](../skills/pm-discover/SKILL.md) | Skims user-facing product surface via `pm-product-scanner` -> writes `PRODUCT_CONTEXT.md` (max 250 lines), `METRICS.md` (max 200 lines), optional `COMPANY_CONTEXT.md` (max 200 lines), and `.pm/ui_tokens.md` (max 150 lines). |
| **Stage 2: `/pm-brainstorm`** (shaping a feature idea across customer demand, roles, alternatives & metrics) | [`../skills/pm-brainstorm/SKILL.md`](../skills/pm-brainstorm/SKILL.md) | Runs the 4+1 Product Goldfish swarm (`pm-value-strategy`, `pm-ux-flows`, `pm-metrics-experiment`, `pm-business-logic` -> `pm-synthesizer`) -> writes `docs/product/<feature-slug>/opportunity_brief.md`. |
| **Stage 3: `/pm-prd`** (drafting a user-focused PRD + built-in 4+1 Product Goldfish review) | [`../skills/pm-prd/SKILL.md`](../skills/pm-prd/SKILL.md) | Drafts pure-product `docs/product/<feature-slug>/prd.md` and polishes it via the built-in 2-round 4+1 Product Goldfish review (`pm_review_report.md`), ready for `/pm-prototype` or `/egm-draft`. |
| **Stage 4: `/pm-prototype`** (generating an interactive HTML preview from an approved PRD) | [`../skills/pm-prototype/SKILL.md`](../skills/pm-prototype/SKILL.md) | Generates zero-build `docs/product/<feature-slug>/prototype.html` (max 400 lines, 4 switchable states + conditional `Role` switcher) using `.pm/ui_tokens.md`, audited via `pm-ux-flows` (`Mode: PROTOTYPE_AUDIT`). |
